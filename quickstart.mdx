This guide walks you through installing Gentle AI and configuring your first AI agent with the Gentleman ecosystem.

## Prerequisites

Before starting, ensure you have:

1. **An AI coding agent installed** (Claude Code, OpenCode, Gemini CLI, Cursor, or VS Code Copilot)
2. **Basic command-line familiarity**
3. **5 minutes** ⏱️

<Note>
Don't have an agent yet? Visit the agent's website to install it first:
- [Claude Code](https://github.com/anthropics/claude-code)
- [OpenCode](https://opencode.ai)
- [Gemini CLI](https://github.com/google/gemini-cli)
- [Cursor](https://cursor.sh)
- [VS Code Copilot](https://code.visualstudio.com/docs/copilot)
</Note>

## Step 1: Install Gentle AI

Run the installation script for your platform:

<CodeGroup>

```bash macOS / Linux

```

```powershell Windows
irm https://raw.githubusercontent.com/Gentleman-Programming/gentle-ai/main/scripts/install.ps1 | iex
```

</CodeGroup>

- Detects your platform and downloads the correct binary
- Verifies the checksum

## Step 2: Launch the Interactive TUI

Start the Gentle AI configuration wizard:

```bash
gentle-ai
```

This launches an interactive TUI (Terminal User Interface) that guides you through the entire configuration process.



## Step 3: Select Your Agent(s)

The TUI automatically detects installed AI agents on your system. Select one or more agents to configure:

- **Claude Code** — Detected at `~/.claude`
- **OpenCode** — Detected at `~/.config/opencode`
- **Gemini CLI** — Detected at `~/.gemini`
- **Cursor** — Detected at `~/.cursor`
- **VS Code Copilot** — Detected at VS Code User profile

<Steps>
  <Step title="Navigate with arrow keys">
    Use **↑/↓** to move between agents.
  </Step>
  
  <Step title="Toggle selection">
    Press **Space** to select/deselect agents.
  </Step>
  
  <Step title="Continue">
    Press **Enter** to proceed.
  </Step>
</Steps>

<Note>
You can configure multiple agents at once. All agents will receive the same Gentleman ecosystem configuration.
</Note>

## CLI Mode (Alternative)

If you prefer non-interactive installation, use CLI flags:

```bash
# Full ecosystem for multiple agents
gentle-ai install \
  --agent claude-code,opencode,gemini-cli \
  --preset full-gentleman

# Minimal setup for Cursor
gentle-ai install \
  --agent cursor \
  --preset minimal

# Custom configuration
gentle-ai install \
  --agent claude-code \
  --component engram,sdd,skills,context7,persona,permissions \
  --skill go-testing,skill-creator \
  --persona gentleman

# Dry-run (preview without applying)
gentle-ai install --dry-run \
  --agent claude-code,opencode \
  --preset full-gentleman
```

### CLI Flags Reference

| Flag | Description | Example |
|------|-------------|----------|
| `--agent`, `--agents` | Agent(s) to configure (comma-separated) | `--agent claude-code,opencode` |
| `--preset` | Configuration preset | `--preset full-gentleman` |
| `--component`, `--components` | Components to install (custom preset only) | `--component engram,sdd,skills` |
| `--skill`, `--skills` | Skills to install (custom preset only) | `--skill go-testing,sdd-propose` |
| `--persona` | Persona mode: `gentleman`, `neutral`, `custom` | `--persona gentleman` |
| `--dry-run` | Preview plan without applying changes | `--dry-run` |

## Managing Backups

Gentle AI creates automatic backups before every configuration change. You can restore to any previous state.

### List Backups

```bash
# Launch TUI and select "Restore from Backup"
gentle-ai
```

Or manually inspect:

```bash
ls -la ~/.gentle-ai/backups/
```

Backup structure:
```
~/.gentle-ai/backups/
├── 20260313_050000/
│   ├── manifest.json
│   └── files/
│       ├── .claude/
│       └── .config/opencode/
└── 20260312_143000/
    └── ...
```

### Restore a Backup

From the TUI:
1. Run `gentle-ai`
2. Select **Restore from Backup**
3. Choose a backup timestamp
4. Confirm restoration

<Warning>
Restoring a backup will **overwrite** your current agent configurations. This action cannot be undone (but a new backup will be created before restoring).
</Warning>

## Per-Project GGA Setup

GGA (Gentleman Guardian Angel) is installed globally, but project-level hooks must be enabled manually:

```bash
cd your-project/

# Initialize GGA for this project
gga init

# Install Git hooks
gga install
```

Now when you commit, GGA will intercept and allow you to switch AI providers on-the-fly.

<Note>
This is intentional — GGA should be an explicit per-repository decision, not a global default.
</Note>

## Troubleshooting

### Agent not detected

If your agent isn't showing up in the TUI:

1. Verify the agent is installed:
   ```bash
   # Claude Code
   ls -la ~/.claude
   
   # OpenCode
   ls -la ~/.config/opencode
   
   # Gemini CLI
   ls -la ~/.gemini
   
   # Cursor
   ls -la ~/.cursor
   ```

2. The agent's config directory must exist (even if empty). Create it manually if needed:
   ```bash
   mkdir -p ~/.claude
   ```

### "npm not found" error

Context7 and Engram require Node.js and npm. Install them:

```bash
# macOS
brew install node

# Ubuntu/Debian
sudo apt install nodejs npm

# Arch
sudo pacman -S nodejs npm

# Windows
winget install OpenJS.NodeJS
```

### Configuration not taking effect

Restart your AI agent after installation. Most agents load configuration at startup.

### Skills not showing up

Verify skills were installed:

```bash
# Claude Code
ls -la ~/.claude/skills/

# OpenCode
ls -la ~/.config/opencode/skills/
```

If empty, re-run the installation with `--component skills`.
