## Installation

Cursor is a **desktop application** and must be installed manually:

1. Download Cursor from [cursor.sh](https://cursor.sh)
2. Install the application
3. Configure with Gentle AI:

```bash
gentle-ai install --agent cursor --preset full-gentleman
```

<Warning>
  Cursor cannot be auto-installed by Gentle AI. Install it manually first, then run `gentle-ai`.
</Warning>

## Configuration

### Config Directory

All Cursor configuration lives in `~/.cursor/`:

```
~/.cursor/
├── rules/
│   └── gentle-ai.mdc      # System prompt (Gentleman persona + SDD orchestrator)
├── settings.json          # Cursor settings
├── mcp.json               # MCP server config
└── skills/                # Skill files (SDD + foundation)
    ├── sdd-init.md
    ├── sdd-propose.md
    ├── go-testing.md
    └── ...
```

### Windows Config Path

```powershell
%USERPROFILE%\.cursor\
```

## System Prompt Strategy

Cursor uses **file replacement** for system prompt via `.mdc` files:

- System prompt file: `~/.cursor/rules/gentle-ai.mdc`
- Cursor automatically loads all `.mdc` files in the `rules/` directory
- Gentle AI writes the full system prompt on every update
- Previous content is backed up before replacement

### Example Structure

```markdown
# Cursor Rules: Gentle AI

## Gentleman Persona

You are a teaching-oriented coding mentor...

## SDD Orchestrator

Spec-Driven Development workflow with 9 phases...

## Skills

You have access to the following skills:
- sdd-init: Bootstrap SDD context
- sdd-propose: Create change proposals
...
```

## MCP Configuration

Cursor uses a **single MCP config file**:

- Config file: `~/.cursor/mcp.json`
- All MCP servers are defined in one file
- Gentle AI merges new servers while preserving existing ones

### Context7 Configuration

Gentle AI installs Context7 MCP server:

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@context7/mcp-server"]
    }
  }
}
```

## Async Sub-agents (v2.5+)

Cursor v2.5+ supports **async sub-agents** with advanced capabilities:

### Features

- **Background execution** — Sub-agents run without blocking the main agent
- **Nested delegation** — Sub-agents can spawn their own sub-agents
- **Tree structure** — Complex delegation hierarchies
- **Progress tracking** — Monitor sub-agent execution in real-time

### How Async Sub-agents Work

1. Main agent receives a complex request
2. Agent spawns multiple async sub-agents
3. Sub-agents execute in parallel in the background
4. Each sub-agent can spawn its own nested sub-agents
5. Results bubble up the delegation tree
6. Main agent synthesizes all results

### Example: Parallel Feature Implementation

```
Main Agent: Implement user authentication
├── Sub-agent 1: Design database schema
│   └── Sub-agent 1.1: Generate migration files
├── Sub-agent 2: Create API endpoints
│   ├── Sub-agent 2.1: Implement login endpoint
│   └── Sub-agent 2.2: Implement logout endpoint
└── Sub-agent 3: Write tests
    ├── Sub-agent 3.1: Unit tests
    └── Sub-agent 3.2: Integration tests
```

All sub-agents execute concurrently, dramatically reducing total execution time.

## What Gentle AI Installs

When you run `gentle-ai install --agent cursor --preset full-gentleman`:

1. **Creates config directory** at `~/.cursor/` (if not present)
2. **Writes system prompt** to `rules/gentle-ai.mdc` with Gentleman persona + SDD orchestrator
3. **Installs 11 skill files** in `~/.cursor/skills/`
4. **Configures Context7 MCP server** in `mcp.json`
5. **Installs GGA binary** globally (opt-in per project with `gga init`)

<Note>
  Cursor itself is **not installed** by Gentle AI. Download it from [cursor.sh](https://cursor.sh) first.
</Note>

## Troubleshooting

### Config Directory Not Found

If `~/.cursor/` doesn't exist:

1. Launch Cursor at least once to initialize config
2. Check if Cursor uses a different config path
3. Create the directory manually: `mkdir -p ~/.cursor/`

### MCP Server Not Loading

If Context7 doesn't load:

1. Check `~/.cursor/mcp.json` exists
2. Verify JSON is valid: `cat ~/.cursor/mcp.json | jq`
3. Test server manually: `npx -y @context7/mcp-server`
4. Restart Cursor to reload MCP config

### Skills Not Available

If skills aren't loading:

1. Check `~/.cursor/skills/` directory exists
2. Verify skill files are markdown: `ls ~/.cursor/skills/*.md`
3. Check system prompt references skills: `grep -i skill ~/.cursor/rules/gentle-ai.mdc`
4. Restart Cursor to reload rules

### Rules Not Loading

If Cursor doesn't load the Gentleman persona:

1. Check `~/.cursor/rules/` directory exists
2. Verify `.mdc` file is present: `ls ~/.cursor/rules/*.mdc`
3. Restart Cursor to reload rules
4. Check Cursor settings for rules configuration
