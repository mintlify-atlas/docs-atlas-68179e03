## Feature Matrix

All agents receive the **full SDD orchestrator** (agent-teams-lite) injected into their system prompt. Every agent supports sub-agent delegation natively, enabling the full SDD orchestration workflow with parallel sub-agents.

## What Gets Installed

Every agent receives:

### Core Components

- **Engram** — Persistent cross-session memory
- **SDD Orchestrator** — Full 9-phase Spec-Driven Development workflow
- **Skills Library** — 11 curated skill files (SDD workflow + foundation skills)
- **Context7 MCP Server** — Real-time framework/library documentation
- **Persona** — Teaching-oriented Gentleman persona (or neutral/custom)
- **Permissions** — Security-first defaults and guardrails

### Optional Components

- **GGA** — Gentleman Guardian Angel AI provider switcher (opt-in per project)
- **Theme** — Gentleman Kanagawa theme overlay

## Installation Method

### CLI Agents (auto-installable)

- **Claude Code** — `npm install -g @anthropic/claude-code`
- **OpenCode** — `npm install -g @anomalyco/opencode`
- **Gemini CLI** — `npm install -g @google/gemini-cli`

### Desktop Agents (manual install)

- **Cursor** — Download from [cursor.sh](https://cursor.sh)
- **VS Code Copilot** — Install VS Code + GitHub Copilot extension

Gentle AI detects which agents are installed and configures them automatically. For desktop agents, install them first, then run `gentle-ai`.

## Config Strategy

Each agent has unique configuration requirements:

| Agent | System Prompt | MCP Config | Skills Dir |
|-------|---------------|------------|------------|
| Claude Code | `~/.claude/CLAUDE.md` | Separate files in `~/.claude/mcp/` | `~/.claude/skills/` |
| OpenCode | `~/.config/opencode/AGENTS.md` | Merged into `opencode.json` | `~/.config/opencode/skills/` |
| Gemini CLI | `~/.gemini/GEMINI.md` | Merged into `settings.json` | `~/.gemini/skills/` |
| Cursor | `~/.cursor/rules/gentle-ai.mdc` | Single `mcp.json` file | `~/.cursor/skills/` |
| VS Code Copilot | `Code/User/prompts/gentle-ai.instructions.md` | `Code/User/mcp.json` | `~/.copilot/skills/` |

## Sub-agent Capabilities

All agents support sub-agent delegation, but implementation varies:

  <Card title="Claude Code" icon="layer-group">

Platform-specific paths are handled automatically. See individual agent pages for Windows-specific notes.
